##Technical Document for Flomad Travel Application

##Introduction

The Flomad Travel application is a dynamic, interactive platform built with Next.js, TypeScript, and React for the frontend, and it integrates seamlessly with a Spring Boot backend API. The application enables users to explore travel destinations, start chats for trip planning, and view AI-generated suggestions. Key features include live chat, map integrations, and user session management.

##Explanation of Core Features and Implementations

###Landing Page

Rotating Background Images: Uses useEffect to create an interval for rotating images.

Chat Initialization: Provides an input field and a button to start a chat session. The handleStartChat function initializes a session via the backend API.

Chat System

Dynamic Suggestions: Dynamically adjusts suggestions based on the context of the user input using generateDynamicPrompts.

Message Handling: Implements user message input, AI-generated responses, and Markdown rendering via ReactMarkdown.

Audio Recorder: Records audio from the user's microphone and processes it for transcription using the AudioRecorder component.

###Map Integration

Real-Time Location Updates: The RightMapPanel component listens for WebSocket updates to display and manage locations on a Google Map.

Map Management: Utilizes map-service.ts to handle marker addition, removal, and map centering.

###Authentication

Guest Tokens: Automatically assigns a guest token if the user is not signed in.

User Authentication: Manages sign-in, sign-up, and user session with AuthContext.

###UI Components

Reusable components like Button, Input, and Card ensure consistent styling across the application.

###WebSocket Integration

The WebSocket client, integrated in RightMapPanel, listens for location updates and processes server events like LOCATION_ADDED or LOCATION_REMOVED.

###Dynamic Imports

Optimizes performance by dynamically importing heavy components like WeProvideBest and FeaturedTourPlaces only when needed.

###Backend Integration

API (api.ts)

The API client, built with Axios, communicates with a Spring Boot backend. Key functionalities include:

Session Management

createSession: Creates a new chat session.

getUserSessions: Fetches user-specific sessions.

updateSession: Updates session metadata.

Message Handling

sendMessagesEntity: Sends user messages to the backend and retrieves AI-generated responses.

sendStreamMessage: Streams AI responses.

Location Updates

getLocationsBySession: Fetches map location data for a session.

Authentication

Supports guest tokens and user authentication tokens.

Implements token interceptors for API security.

###Challenges and Solutions

Challenge: Managing dynamic prompts for diverse user queries.

Solution: Implemented generateDynamicPrompts to adjust suggestions based on user context dynamically.

Challenge: Ensuring responsive design across devices.

Solution: Used Tailwind CSS for consistent and adaptable UI styling.

Challenge: Real-time location updates.

Solution: Integrated WebSocket for live updates and handled message parsing robustly.

###Future Improvements

Enhanced Map Features: Add route planning and geofencing capabilities.

AI Enhancements: Introduce multilingual support and advanced AI-driven suggestions.

Analytics: Implement user behavior tracking to improve user experience.

Offline Support: Cache key components for offline access.
